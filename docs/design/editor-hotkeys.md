# Editor Hotkeys

### Items/selection

`Cmd+[` - send backward<br>
`Cmd+]` - send forward<br>
`Alt+Drag` - Duplicate and move selection<br>
`Cmd+Z` - Undo action<br>
`Cmd+Shift+Z` - Redo action<br>
`Arrow keys` - Move selection<br>
`Shift+Arrow keys` - Nudge selection by micro<br>
`Cmd+D` - Duplicate selection<br>
`Cmd+C/Cmd+V` - Copy/paste selection<br>
`Alt+Resize` - Mirror resize<br>
`Shift+Resize` - Resize with ratio preserved<br>
`Alt+Shift+Resize` - Mirror resize with ratio preserved<br>
`Alt+Hover` - hold to see distances to other items/boundaries<br>

### View
`Ctrl+H` - show/hide UI<br>
`Ctrl+G` - toggle between three grid states: grid+panel, grid, no grid 

### Tools
`R` - toggle Rectangle tool<br>
`T` - toggle Text tool
