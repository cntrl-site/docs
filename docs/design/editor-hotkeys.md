# Editor Hotkeys

### Items/selection

 `Cmd+[` - send backward
 `Cmd+]` - send forward
 `Alt+Drag` - Duplicate and move selection
 `Cmd+Z` - Undo action
 `Cmd+Shift+Z` - Redo action
 `Arrow keys` - Move selection
 `Shift+Arrow keys` - Nudge selection by micro
 `Cmd+D` - Duplicate selection
 `Cmd+C/Cmd+V` - Copy/paste selection
 `Alt+Resize` - Mirror resize
 `Shift+Resize` - Resize with ratio preserved
 `Alt+Shift+Resize` - Mirror resize with ratio preserved
 `Alt+Hover` - hold to see distances to other items/boundaries

### View
 `Ctrl+H` - show/hide UI
 `Ctrl+G` - toggle between three grid states: grid+panel, grid, no grid 

### Tools
 `R` - toggle Rectangle tool
 `T` - toggle Text tool
